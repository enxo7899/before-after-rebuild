Edit your website

Change anything below, then press Download site.json. Replace content/site.json with the downloaded file and the site rebuilds itself (steps at the bottom). Nothing is sent anywhere: this page only reads and writes a file on your computer.

How the change goes live

  1. Press Download site.json (it only enables when every field is valid).
  2. On GitHub, open content/site.json, choose Edit, paste the new file contents and commit. Or drag the file into the content folder of the repository.
  3. The deploy workflow runs npm run build and publishes the update, usually within a minute or two. On Netlify the same happens through its build command.
